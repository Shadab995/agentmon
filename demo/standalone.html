Your coding agents, as pocket creatures.

Every Claude Code session hatches a creature that walks along the bottom of your browser. It hops when it needs your approval, shows what it's doing, and evolves as it gets work done.

    A PermissionRequest hook holds the request until you tap Allow, Always or Deny on the pet. The terminal prompt keeps working, so you can answer in either place.

    Set it up on your computer

    1. Unzip the project and run the installer
      node bin/agentmon.js init
    2. Load the extension in Chrome Open chrome://extensions, turn on Developer mode, click Load unpacked and pick ~/.agentmon/extension.
    3. Start Claude Code, or run the demo
      node ~/.agentmon/bin/agentmon.js demo
